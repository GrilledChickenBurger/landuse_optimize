# Runner Module

土地利用优化算法的核心运行器模块，包含模拟退火(SA)和遗传算法(GA)两种优化算法的实现。

## 文件说明

### `__init__.py`
- **功能**: 运行器工厂函数，提供统一的优化器创建接口
- **核心函数**: `create_runner()` - 根据类型创建SA或GA优化器实例
- **支持类型**: SA (模拟退火)

### `SA.py`
- **功能**: 模拟退火优化器实现
- **核心类**: `SA` - 模拟退火算法类
- **算法特点**: 基于温度控制的随机搜索，支持局部搜索和全局优化
- **关键方法**: 
  - `run()`: 执行模拟退火优化过程
  - `update_score_lists()`: 更新目标函数得分记录


## 使用方式

### 主要调用路径
1. **优化管道** (`pipelines/run_runner.py`): 导入`create_runner`创建优化器实例
2. **运行器工具** (`utils/runner_utils.py`): 提供优化器所需的辅助函数

### 优化器创建示例
```python
from runner import create_runner

# 创建模拟退火优化器
sa_runner = create_runner('SA', config=config, **kwargs)

```

## 核心功能特性

### 模拟退火优化器 (SA)
- **温度控制**: 初始温度、终止温度、冷却速率
- **新方案生成**: 基于温度的概率控制，支持小/中/大范围变化
- **接受准则**: Metropolis准则，允许接受较差解以避免局部最优
- **约束处理**: 硬约束和类别约束的完整支持


## 输入输出格式

### 输入参数
- `config`: 优化器配置参数（温度、种群大小等）
- `data_dict`: 包含驱动因子、生态系统服务数据的字典
- `index`: 土地利用索引（如'10_764_5'）
- `weight_dict`: 生态系统服务权重配置
- `use_landscape`: 是否使用景观格局约束

### 输出结果
- `best_plan`: 最优土地利用方案，形状为[1,1,128,128]
- 得分记录: 目标函数各项得分的完整历史记录
- 可视化结果: 优化过程和结果的图表展示

## 优化目标函数

### 综合目标函数
```
目标函数 = 变化得分 - λ_ES × ES得分 + λ_LS × 景观得分
```

### 得分项说明
- **变化得分**: 衡量与预测变化区域的接近程度
- **ES得分**: 生态系统服务综合得分（粮食、碳汇、水源、文化）
- **景观得分**: 景观格局破碎化约束得分

## 约束处理机制

### 硬约束 (Hard Restrict)
- 不可修改的区域（红线区域）
- 基于预测变化区域的限制

### 类别约束 (Class Restrict)
- 特定土地利用类别（51、53）的修改限制
- 不能修改为非5类别的约束

### 景观约束 (Landscape Constraint)
- 可选约束，控制景观破碎化程度
- 基于连通性和空间布局的评估
