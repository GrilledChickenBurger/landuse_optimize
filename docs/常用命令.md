# 创建虚拟环境

## 1. 确认 Python 版本

```bash
# 查看系统 Python 位置
which python3
# 例如 /usr/bin/python3, /root/miniconda3/bin/python3
```

## 2. 创建虚拟环境

```bash
# 使用系统 Python 创建 venv
/root/miniconda3/bin/python3 -m venv .venv
```

## 3. 虚拟环境启动

```bash
source /root/autodl-tmp/landuse_optimize/.venv/bin/activate
```

## 4. 安装依赖

```bash
pip install -r requirements.txt
```

# 后台运行命令

nohup 是"No Hang Up"的缩写，它能让程序忽略终端断开信号（SIGHUP），从而在你关闭终端后继续在后台运行

## 开始运行+记录日志

```bash
nohup python -u main.py > /root/autodl-tmp/landuse_optimize/stability.log 2>&1 &
```

- nohup：使程序忽略挂断信号，终端关闭后继续运行。
- python -u train.py：运行你的脚本。-u 参数（unbuffered）很重要，它确保日志能实时写入文件，而不是等到程序结束才写入。
- > ：将标准输出重定向到后面指定的文件。
- /root/autodl-tmp/my_train.log：日志文件保存的路径。建议放在 /root/autodl-tmp/ 下，因为这块是数据盘，重启实例后数据还在。
- 2>&1：将标准错误（stderr，即程序报错信息）也重定向到标准输出（stdout，即普通打印信息），确保所有信息都记录在同一个日志文件中。
- &：将整个命令放到后台执行，释放你的终端。

## 查看日志最后n行

```bash
tail -n 100 /root/autodl-tmp/stability.log
```

## 实时追踪日志（滚动显示新增内容）

```bash
tail -f /root/autodl-tmp/stability.log
```
