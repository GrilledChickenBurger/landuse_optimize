# 消融实验操作手册

> 本文档以最简方式说明如何启动稳定性实验与 A/B/C 消融实验、需要哪些输入、会得到哪些输出、以及后续如何作图。不涉及代码实现细节。

---

## 1. 实验概述

本项目有两类消融实验：

| 实验 | 模式 | 目的 | 实验组 |
|---|---|---|---|
| **稳定性实验** | `mode='stability'` | 验证 SA/GA 多次运行结果是否稳定 | 仅 A_guided（完整方法），每个样本跑 5 次 |
| **消融实验** | `mode='ablation'` | 验证预测引导（pred_diff）是否有效 | A_guided / B_unguided / C_random 三组，每组每个样本跑 5 次 |

---

## 2. 前置条件

1. **ANN 模型权重**：`configs/optimizerConfig.yaml` 中 `model.model_path` 指向有效的 checkpoint。
2. **代表性样本**：运行 `scripts/select_representative_samples.py` 生成 `_data/representative_samples.json`（含 10 个样本索引及 Q1–Q5 分层信息）。
3. **评分配置**：`configs/score_cfg.yaml` 存在且参数正确。

---

## 3. 启动方式

在 `main.py` 中取消注释对应入口：

### 3.1 稳定性实验

```python
# 先跑 SA
run_ablation_pipeline(
    opt_cfg_path="configs/optimizerConfig.yaml",
    score_cfg_path="configs/score_cfg.yaml",
    idxs=idxs,               # 从 representative_samples.json 读取
    mode='stability',
    n_repeats=5,
)

# 再跑 GA（改 optimizerConfig.yaml 中 runner.type 为 GA 后重新执行）
# 两次运行会生成两个 timestamp 目录
```

### 3.2 A/B/C 消融实验

```python
run_ablation_pipeline(
    opt_cfg_path="configs/optimizerConfig.yaml",
    score_cfg_path="configs/score_cfg.yaml",
    idxs=idxs,
    mode='ablation',
    n_repeats=5,
)
```

### 3.3 断点续传

若中途退出，在同一入口中设置：

```python
run_ablation_pipeline(
    ..., mode='stability',  # 或 'ablation'
    is_processed=True,
    processed_timestamp="20260602_120000",  # 上次运行的时间戳
)
```

程序会跳过已存在 `convergence.json` 的 run，跑完后自动重新写出 `*_runs.csv`。

## 4. 结果目录结构

运行结束后，结果保存在 `results/ablation/<timestamp>/`：

```
results/ablation/<timestamp>/
├── ablation_summary.json          # 全局清单（mode、runner_type、实验列表）
├── A_guided/                      # 稳定性实验只有这一组；消融实验还有 B/C
│   ├── manifest.json              # 该组覆写的配置与 flags
│   ├── run_0/                     # 第 1 次独立重复
│   │   ├── 10_479_5/              # 样本 index
│   │   │   ├── convergence.json   # 收敛统计
│   │   │   ├── performance.json   # 性能指标（ES 分项等）
│   │   │   ├── total_score_list.npy  # 逐迭代目标函数值（供收敛曲线）
│   │   │   └── best_score.png     # 最终方案可视化
│   │   └── ...
│   ├── run_1/ ... run_4/
│   └── ...
├── B_unguided/                    # 仅 ablation 模式有
├── C_random/                      # 仅 ablation 模式有
└── plots/                         # 后处理产出（见第 5 节）
    ├── stability_runs.csv         # 稳定性实验原始记录表
    ├── ablation_runs.csv          # 消融实验原始记录表（仅 ablation 模式）
    └── ...
```

## 5. 关键输出文件含义

### 5.1 原始记录表（pipeline 跑完即生成）

| 文件 | 说明 |
|---|---|
| `plots/stability_runs.csv` | 稳定性实验：每行一次独立运行。字段 `sample_id, n_pred, level, algorithm, config, run_idx, F_final, ESV, Runtime, T95` |
| `plots/ablation_runs.csv` | 消融实验：同上，但覆盖 A/B/C 三组，通过 `config` 列区分 |

字段含义：
- `sample_id`：样本编号（如 `10_479_5`）
- `n_pred` / `level`：该样本预测变化像素数及其 Q1–Q5 分层
- `algorithm`：`SA` 或 `GA`
- `config`：`A`（完整方法）、`B`（无位置引导）、`C`（随机约束）
- `run_idx`：第几次独立运行（1–5）
- `F_final`：最终综合目标函数值（越小越好）
- `ESV`：最终生态系统服务得分（归一化，约 0~1）
- `Runtime`：该次运行耗时（秒）
- `T95`：首次达到最优值 95% 的迭代步数

### 5.2 单次 run 产物

| 文件 | 说明 |
|---|---|
| `convergence.json` | 单次 run 的收敛统计：`final_best`（F_final）、`es_score`（ESV）、`iter_to_95pct`（T95）、`wall_time_sec`（Runtime） |
| `performance.json` | 性能评估：变化区域指标、ES 四项（food/carbon/water/culture）分项值、景观破碎化指标 |
| `total_score_list.npy` | 逐迭代目标函数值序列，供绘制收敛曲线 |

### 5.3 后处理汇总表（调用 `run_ablation_plots_pipeline` 后生成）

**稳定性实验**：

| 文件 | 说明 | 论文位置 |
|---|---|---|
| `stability_per_sample.csv` | 每个样本的 μ/σ/CV/95%CI（SA+GA 合并后 20 行） | 正文稳定性论述数据源 |
| `stability_summary.csv` | 跨样本汇总：平均 CV、最大 CV、CV≤5% 样本占比（2 行） | `tab:stability-summary` |
| `stability_cv_line.png` | 10 样本按 `n_pred` 升序的 SA vs GA 双折线图 | `fig:stability-cv-line` |
| `stability_table_A_guided.csv` | 单组 per_sample 聚合（mean±std / 95%CI） | — |

**消融实验**：

| 文件 | 说明 | 论文位置 |
|---|---|---|
| `ablation_mean_table.csv` | 每个样本 × 每配置取均值（表2） | — |
| `ablation_improvement_table.csv` | 每个样本 A vs B / A vs C 的提升率（表3） | — |
| `ablation_summary_table.csv` | 跨样本汇总提升率的均值与范围（最终汇总表） | `tab:ablation-summary` |
| `ablation_compare_table.csv` | A/B/C 三组并排对比（含相对 A 的百分比变化） | — |
| `ablation_convergence_<idx>.png` | A/B/C 三组单样本收敛曲线对比 | `fig:ablation-convergence` |
| `boxplot_final_f.png` | A/B/C 最终目标函数箱线图 | `fig:ablation-boxplot` |

## 6. 后续作图流程

### 6.1 稳定性实验（SA + GA 合并）

```python
# SA 和 GA 分别跑完后，用 SA 的 timestamp 作为主目录，GA 作为 sibling
run_ablation_plots_pipeline(
    ablation_root="results/ablation/<SA_timestamp>",
    sibling_ablation_roots=["results/ablation/<GA_timestamp>"],
)
```

产出：
- `stability_per_sample.csv`
- `stability_summary.csv`
- `stability_cv_line.png`
- 各样本收敛叠图

### 6.2 消融实验

```python
run_ablation_plots_pipeline(
    ablation_root="results/ablation/<timestamp>",
)
```

产出：
- `ablation_mean_table.csv`
- `ablation_improvement_table.csv`
- `ablation_summary_table.csv`
- `ablation_compare_table.csv`
- A/B/C 收敛对比图
- 箱线图

## 7. 图表含义速查

| 图表 | 表达的核心结论 |
|---|---|
| **stability_cv_line.png** | SA 和 GA 在所有样本上的 CV 是否都低于 5%，证明算法稳定 |
| **stability_convergence_all_A_guided.png** | 同一样本多次运行的曲线是否聚集，证明收敛路径稳定 |

| **boxplot_final_f.png** | A 组最终目标函数是否显著优于 B/C，证明完整方法更优 |
| **ablation_summary_table.csv** | 量化 A vs B/C 在收敛速度、运行时间、ESV 上的平均提升率 |

## 8. 常见问题

**Q: 为什么 stability 和 ablation 要分开跑？**
A: 稳定性实验只跑 A 组，时间成本约 1~2 小时（5 样本 × 5 次）；消融实验跑 A/B/C 三组，约 3~6 小时。两者目的不同，可根据需要单独执行。

**Q: ESV 列的值是怎么来的？**
A: 每次 run 结束后，用最终最优方案 `best_plan` 重新计算一次生态系统服务相对得分 `es_score`（归一化到 0~1），写入 `convergence.json`，再由 `write_*_runs_csv` 提取到 CSV 中。

**Q: 跑 ablation 模式时会不会自动产出 stability_runs.csv？**
A: 不会。ablation 模式产出的是 `ablation_runs.csv`，内含 A/B/C 三组数据。如果后续需要 stability 分析，可过滤 `config='A'` 的行使用，或单独跑一次 `mode='stability'`。
