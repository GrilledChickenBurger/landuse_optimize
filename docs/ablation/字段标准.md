# 稳定性实验与消融实验统一原始数据记录规范

> 本文档定义 **一条原始记录** 应包含的全部字段，使得该数据可同时支撑：
>
> - **稳定性实验**（同一样本、同一配置多次运行的结果波动分析，关注 (F(S)) 和 Runtime 的变异系数）
> - **消融实验**（不同引导配置 A/B/C 间的提升率计算，关注 T95、Runtime、ESV）
>
> 遵循“一次实验、一张表记录、多种汇总”的原则，避免数据冗余或遗漏。

***

## 1. 原始记录表结构

每条记录对应 **一次独立运行**。\
以下字段为实验完成后必须保存的 **最小集合**。

| 字段名            | 类型              | 说明                                                                                       |
| -------------- | --------------- | ---------------------------------------------------------------------------------------- |
| `Sample_ID`    | string          | 样本唯一编号，如 `S01`、`S10`                                                                     |
| `Change_Level` | string          | 变化区域等级，如 `低`、`中`、`高`（与抽样策略一致）                                                            |
| `Algorithm`    | string          | 优化算法，取值 `SA` 或 `GA`                                                                      |
| `Config`       | string          | 引导配置类型：• `A` — 空间显式引导（完整模型）• `B` — 仅数量限制• `C` — 随机区域引导（稳定性实验仅需 `A` 配置；消融实验需 `A`、`B`、`C`） |
| `Run`          | integer         | 独立运行序号（1, 2, 3, …），对每个 `Sample_ID + Algorithm + Config` 组合从 1 连续编号                       |
| `F_S`          | float           | 最终综合目标函数值（含预测引导奖励项）                                                                      |
| `ESV`          | float           | 最终生态系统服务价值                                                                               |
| `Runtime`      | float           | 总运行时间（秒）                                                                                 |
| `T95`          | integer / float | 达到目标函数终值 95% 时的迭代次数（或函数评价次数）                                                             |

> **注意**：
>
> - 稳定性实验主要使用 `F_S` 和 `Runtime`，`ESV` 可选记录；`T95` 可选。
> - 消融实验必须记录 `T95`、`Runtime`、`ESV`（`F_S` 可选，但统一记录可避免数据缺失）。
> - 若某次运行未记录非必需字段（如稳定性实验中的 `T95`），可留空或记为 `NA`，不影响后续分析。

## 3. 使用该表生成各实验所需数据

### 3.1 稳定性实验

**目标**：计算每个样本在 `Config = 'A'` 下，多次独立运行的 (F(S)) 和 Runtime 的变异系数，并跨样本汇总。

**筛选**：`Algorithm = 'SA'` 或 `'GA'`，且 `Config = 'A'`。

**聚合步骤**：

1. 按 `Sample_ID`, `Algorithm` 分组。
2. 对每组计算：
   - `Mean_F_S = mean(F_S)`, `SD_F_S = std(F_S)`, `CV_F_S = (SD_F_S / Mean_F_S) * 100`。
   - `Mean_RT = mean(Runtime)`, `SD_RT = std(Runtime)`, `CV_RT = (SD_RT / Mean_RT) * 100`。
3. 得到每个样本的两个 CV 指标（表2风格）。
4. 跨样本，对每种算法分别汇总 `CV_F_S` 和 `CV_RT`：
   - 平均 CV、最大 CV、CV ≤ 5% 样本占比。

**最终生成表格**：

| Algorithm | Metric  | Mean CV (%) | Max CV (%) | CV ≤ 5% 样本占比 (%) |
| --------- | ------- | ----------- | ---------- | ---------------- |
| SA        | F(S)    | \[值]        | \[值]       | \[值]             |
| SA        | Runtime | \[值]        | \[值]       | \[值]             |
| GA        | F(S)    | \[值]        | \[值]       | \[值]             |
| GA        | Runtime | \[值]        | \[值]       | \[值]             |

**所需图表**：

- 箱线图：使用原始 `F_S` 和 `Runtime` 数据（分组依据 `Sample_ID` 和 `Algorithm`），同时展示两组算法的分布。

### 3.2 消融实验

**目标**：计算 A vs B、A vs C 在 T95、Runtime、ESV 三个维度上的提升率。

**筛选**：`Algorithm = 'SA'` 或 `'GA'`，所有配置 `A`, `B`, `C`。

**聚合步骤**：

1. 按 `Sample_ID`, `Algorithm`, `Config` 分组，计算均值：
   - `Mean_T95 = mean(T95)`
   - `Mean_Runtime = mean(Runtime)`
   - `Mean_ESV = mean(ESV)`
2. 透视，使每个样本一行，包含 `A_T95`, `B_T95`, `C_T95`, `A_Runtime`, `B_Runtime`, `C_Runtime`, `A_ESV`, `B_ESV`, `C_ESV`。
3. 计算提升率（分母为对照组）：
   - `T95_Reduction_AvsB = (B_T95 - A_T95) / B_T95 * 100`
   - `Runtime_Reduction_AvsB = (B_Runtime - A_Runtime) / B_Runtime * 100`
   - `ESV_Improvement_AvsB = (A_ESV - B_ESV) / B_ESV * 100`
   - 同理计算 A vs C 的三个指标。
4. 跨样本汇总：对上述提升率计算均值与范围（min–max）。

**最终生成表格**：

| Algorithm | Metric            | A vs B 均值 | A vs B 范围  | A vs C 均值 | A vs C 范围  |
| --------- | ----------------- | --------- | ---------- | --------- | ---------- |
| SA        | T95 Reduction     | \[值]      | \[min–max] | \[值]      | \[min–max] |
| SA        | Runtime Reduction | \[值]      | \[min–max] | \[值]      | \[min–max] |
| SA        | ESV Improvement   | \[值]      | \[min–max] | \[值]      | \[min–max] |
| GA        | T95 Reduction     | \[值]      | \[min–max] | \[值]      | \[min–max] |
| GA        | Runtime Reduction | \[值]      | \[min–max] | \[值]      | \[min–max] |
| GA        | ESV Improvement   | \[值]      | \[min–max] | \[值]      | \[min–max] |

**所需图表**：

- 提升率柱状图：使用步骤3的逐样本提升率数据。
- 收敛曲线（需额外记录逐迭代目标值）：选取代表性样本，绘制 A/B/C 三组的均值曲线与各 run 细线，用不同颜色区分配置。

## 4. 数据记录建议

- **统一命名**：所有实验共用一个原始数据表（推荐 CSV 或数据库），通过 `Config` 字段区分实验条件。
- **运行次数**：稳定性实验每个样本至少 3\~5 次，消融实验每个配置至少 3 次（5 次更佳）。稳定性实验的 Config=A 运行次数可直接复用为消融实验 A 配置的数据，节省计算资源。
- **自动汇总**：编写脚本（Python/pandas）一次性读取该表，按上述聚合逻辑输出所有汇总表格和图表所需中间数据，确保可重现性。
- **补充记录**：若需绘制收敛曲线，需另建一张“迭代过程表”，字段为 `Sample_ID, Algorithm, Config, Run, Iteration, Objective_Value`，通过联合键与原始表关联。
