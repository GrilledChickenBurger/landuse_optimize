# 消融实验数据整合流程

> 本文档展示如何从最原始的“每次独立运行”数据出发，
> 逐步汇总到论文中最终呈现的消融实验汇总表格。
> 示例仅展示 **SA 算法**，GA 流程完全对称，仅需替换算法标签。

---

## 1. 原始运行级数据（颗粒度：每次独立运行）

假设每个样本 × 每个配置（A/B/C）独立运行 **3 次**（建议 ≥ 3，理想为 5）。

**表1：原始记录示例 —— 样本 S01，算法 SA**

| Sample_ID | Config | Run | T95 (iter) | Runtime (s) | Final ESV | F(S) (综合目标) |
| --------- | ------ | --- | ---------- | ----------- | --------- | --------------- |
| S01       | A      | 1   | 120        | 500         | 0.852     | 0.876           |
| S01       | A      | 2   | 130        | 520         | 0.844     | 0.869           |
| S01       | A      | 3   | 125        | 510         | 0.849     | 0.873           |
| S01       | B      | 1   | 210        | 820         | 0.798     | 0.761           |
| S01       | B      | 2   | 200        | 790         | 0.803     | 0.772           |
| S01       | B      | 3   | 195        | 800         | 0.799     | 0.768           |
| S01       | C      | 1   | 180        | 710         | 0.821     | 0.803           |
| S01       | C      | 2   | 175        | 700         | 0.828     | 0.812           |
| S01       | C      | 3   | 185        | 720         | 0.817     | 0.799           |

> 此类原始表需要对所有 10 个样本完整记录，并分别保存 SA 和 GA 两组。

---

## 2. 第一步整合：按样本、配置取均值

对每个样本 × 配置，计算 3 次（或 5 次）独立运行的算术均值，
作为该配置在该样本上的代表值，以消除运行随机性。

**表2：样本 S01 各配置均值（SA）**

| Sample_ID | Config | Mean T95 | Mean Runtime | Mean ESV |
| --------- | ------ | -------- | ------------ | -------- |
| S01       | A      | 125.0    | 510.0        | 0.848    |
| S01       | B      | 201.7    | 803.3        | 0.800    |
| S01       | C      | 180.0    | 710.0        | 0.822    |

对全部 10 个样本重复此操作，得到 10 组类似数据（或一个长表）。

---

## 3. 第二步整合：计算每个样本的提升率

提升率定义（以 A 为实验组，B/C 为对照组，对照组为分母）：

- **T95 Reduction** = (对照组 T95 − A 组 T95) / 对照组 T95 × 100%
- **Runtime Reduction** = (对照组 Runtime − A 组 Runtime) / 对照组 Runtime × 100%
- **ESV Improvement** = (A 组 ESV − 对照组 ESV) / 对照组 ESV × 100%

**示例：样本 S01 的提升率计算**

- **A vs B**：
  - T95 Reduction = (201.7 − 125.0) / 201.7 × 100% = **38.0%**
  - Runtime Reduction = (803.3 − 510.0) / 803.3 × 100% = **36.5%**
  - ESV Improvement = (0.848 − 0.800) / 0.800 × 100% = **6.0%**

- **A vs C**：
  - T95 Reduction = (180.0 − 125.0) / 180.0 × 100% = **30.6%**
  - Runtime Reduction = (710.0 − 510.0) / 710.0 × 100% = **28.2%**
  - ESV Improvement = (0.848 − 0.822) / 0.822 × 100% = **3.2%**

**表3：SA 算法所有样本的提升率总览（中间数据）**

| Sample_ID | A vs B T95 Red.% | A vs B RT Red.% | A vs B ESV Imp.% | A vs C T95 Red.% | A vs C RT Red.% | A vs C ESV Imp.% |
| --------- | ---------------- | --------------- | ---------------- | ---------------- | --------------- | ---------------- |
| S01       | 38.0             | 36.5            | 6.0              | 30.6             | 28.2            | 3.2              |
| S02       | 42.1             | 39.2            | 5.2              | 33.5             | 31.1            | 2.8              |
| ...       | ...              | ...             | ...              | ...              | ...             | ...              |
| S10       | 35.2             | 33.8            | 6.8              | 29.8             | 27.5            | 4.1              |

> 表格中每一行对应一个样本的提升率，这张表可直接用于绘制提升率箱线图或柱状图。

---

## 4. 最终整合：跨样本汇总统计

对上一步得到的 10 个样本提升率，计算：

- **均值**（Mean）
- **范围**（最小值–最大值，或加标准差/置信区间）

**SA 算法汇总结果（示例数据）**

| 对比   | 指标              | 均值 | 范围 (min–max) |
| ------ | ----------------- | ---- | -------------- |
| A vs B | T95 Reduction     | 38.5 | 35.2 – 42.1    |
| A vs B | Runtime Reduction | 36.8 | 33.8 – 39.2    |
| A vs B | ESV Improvement   | 5.9  | 5.2 – 6.8      |
| A vs C | T95 Reduction     | 31.2 | 29.8 – 33.5    |
| A vs C | Runtime Reduction | 29.4 | 27.5 – 31.1    |
| A vs C | ESV Improvement   | 3.5  | 2.8 – 4.1      |

GA 算法经过同样的流程后，也会得到一组对应的汇总值。

## 附录：数据流总结

| 处理阶段      | 输入             | 输出                 | 颗粒度             |
| ------------- | ---------------- | -------------------- | ------------------ |
| 1. 原始记录   | 每次运行原始数据 | 表1（运行级）        | 样本 × 配置 × Run  |
| 2. 配置均值   | 表1              | 表2（样本‑配置均值） | 样本 × 配置        |
| 3. 提升率计算 | 表2              | 表3（样本‑提升率）   | 样本 × 对比 × 指标 |
| 4. 跨样本汇总 | 表3              | 最终论文表格         | 算法 × 对比 × 指标 |

> 所有计算均可通过 Excel / Python (pandas) 自动化完成，
> 并保留原始运行数据作为补充材料或可重现性凭证。
