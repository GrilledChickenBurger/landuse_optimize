# LU Optim 土地利用优化系统实验说明

## 实验环境与框架

本章在支持 CUDA 的 GPU 设备上，使用 PyTorch 深度学习框架实现了土地利用变化检测与优化系统。系统支持多种语义分割网络架构，用于土地利用变化预测任务。

## 模型架构与配置

### 支持的模型类型

系统支持以下深度学习模型架构：

1. **AttU-Net** - 注意力U-Net模型
2. **U-Net** - 基础U-Net模型
3. **FCN** - 全卷积网络
4. **SegFormer** - 基于Transformer的语义分割网络
5. **TransUNet** - Transformer与U-Net的混合架构

### 默认模型配置

- **输入通道数**: 驱动因子数量 + 6 (LU通道)
- **输出通道数**: 1 (变化检测任务)
- **图像尺寸**: 128 × 128 像素

## 随机优化算法参数配置

### 模拟退火算法 (SA) 配置

#### 温度控制参数

- **初始温度 (T_start)**: 100
- **终止温度 (T_end)**: 0.1
- **降温率 (cooling_rate)**: 0.9995
- **温度控制策略**: 指数降温策略

#### 迭代控制参数

- **最大无改进迭代次数**: 1000
- **最优解停滞阈值**: 3000
- **打印频率**: 每100步打印一次输出
- **可视化频率**: 每500步可视化一次输出

#### 新方案生成策略

系统采用基于温度的自适应变化策略：

- **小范围变化**: 最大面积为 `pred_diff_pixelnum × 0.25`
- **中范围变化**: 最大面积为 `pred_diff_pixelnum × 0.5`
- **大范围变化**: 最大面积为 `pred_diff_pixelnum`
- **回退操作**: 恢复到原始土地利用状态

变化尺度根据预测变化像素数量动态调整（`get_scale_minmax_dict()`），三档比例随 pred_diff 非零像素数变化：

- **温度较高时**: 倾向于大范围变化
- **温度较低时**: 倾向于小范围变化和回退
- **优化停滞时**: 增加回退概率

### 遗传算法 (GA) 配置

#### 种群参数

- **初始种群大小**: 30
- **最终种群大小**: 8
- **最大迭代次数**: 3000
- **交叉率**: 0.8
- **变异率**: 1.0

#### 选择策略

系统支持多种遗传算法策略变体：

| 变体编号   | 父本选择方法 | 父本来源  | 精英保留比例 | 未交叉个体处理 | 精英是否变异 |
| ---------- | ------------ | --------- | ------------ | -------------- | ------------ |
| GA1 (基准) | 轮盘赌       | 全部种群  | 10%          | 直接复制       | 否           |
| GA2        | 锦标赛(k=2)  | 全部种群  | 10%          | 直接复制       | 否           |
| GA3        | 轮盘赌       | 前20%精英 | 10%          | 直接复制       | 否           |
| GA4        | 轮盘赌       | 全部种群  | 0%           | 直接复制       | 否           |
| GA5        | 轮盘赌       | 全部种群  | 50%          | 直接复制       | 否           |
| GA6        | 轮盘赌       | 全部种群  | 10%          | 复制后变异     | 否           |
| GA7        | 轮盘赌       | 全部种群  | 10%          | 直接复制       | 是           |

#### 自适应机制

- **种群大小自适应**: 根据遗传代数比例和优化进度动态调整
- **终止条件自适应**: 根据优化进度调整最大无改进迭代次数
- **变化尺度自适应**: 初始化时按比例分配不同尺度变化

### 优化目标函数

#### 复合目标函数

系统采用多目标优化框架，目标函数包含三个主要组成部分：

1. **变化得分 (Change Score)**
   - 衡量预测变化与实际变化的一致性
   - 范围: [-∞, 1]，越大表示越好

2. **生态系统服务得分 (ES Score)**
   - 包含四个生态系统服务指标：
     - **食物生产 (food)**
     - **碳储存 (carbon)**
     - **水资源保护 (water)**
     - **文化服务 (culture)**
   - 范围: [0, 1]，越大表示越好

3. **景观破碎化得分 (Landscape Score)**
   - 可选约束，衡量土地利用的景观格局质量
   - 基于 scipy.ndimage.label 连通组件分析 + 自定义斑块纯度/距离指标（纯 NumPy/SciPy 实现）。FragStats 仅用于后处理性能评估阶段

#### 权重配置

系统支持多种场景的权重配置：

- **默认场景**: 食物0.25, 碳储存0.25, 水资源0.25, 文化服务0.25
- **企业场景**: 碳储存0.5, 水资源0.5
- **农业场景**: 食物0.8, 碳储存0.1, 水资源0.1
- **旅游场景**: 文化服务1.0

### 约束条件处理

#### 硬约束 (Hard Constraints)

- **不可修改区域**: 特定区域禁止任何土地利用变更
- **边界保护**: 确保土地利用变更不超出合理范围

#### 类别约束 (Class Constraints)

- **特定类别保护**: 类别51、53无法修改为非5类别
- **土地利用转换规则**: 遵循合理的土地利用转换逻辑

#### 变化阈值控制

- **最小变化区域**: 30像素阈值，小于该值不进入优化过程
- **变化区域筛选**: 可选仅使用有变化的样本进行优化
