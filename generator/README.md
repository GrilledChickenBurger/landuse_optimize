# Generator Module

土地利用优化算法中的新方案生成器模块，专门为随机优化算法提供新的土地利用方案生成。

## 文件说明

### `sa.py`
- **功能**: 模拟退火算法的新方案生成器
- **核心函数**:
  - `generate_new_plan()`: 在当前方案基础上生成新的土地利用方案
  - `area_wise_change()`: 区域级别的变化操作
  - `area_wise_return()`: 区域级别的回退操作（恢复到原始状态）

## 使用方式

### 主要调用路径
1. **遗传算法** (`runner/GA.py`): 导入`generate_new_plan`生成新方案
2. **模拟退火算法** (`runner/SA.py`): 导入`generate_new_plan`生成新方案

### 核心功能

#### 新方案生成策略
- **小范围变化** (small): 100-200像素区域
- **中范围变化** (mid): 200-400像素区域  
- **大范围变化** (large): 400-800像素区域
- **回退操作** (return): 恢复到原始土地利用状态

#### 变化概率控制
根据当前温度比例和目标函数优化步数动态调整变化策略概率：
- 温度较高时：倾向于大范围变化
- 温度较低时：倾向于小范围变化和回退
- 优化停滞时：增加回退概率

#### 约束处理
- **硬约束** (hard_restrict): 不可修改的区域
- **类别约束** (cls_restrict): 特定类别（51、53）不能修改为非5类别
- **区域有效性检查**: 确保选中区域不包含约束像素

## 输入输出格式

### 输入参数
- `cur_plan`: 当前土地利用方案，形状为[1,1,128,128]
- `ori_plan`: 原始土地利用方案，形状为[1,1,128,128]
- `T_ratio`: 当前温度与初始温度的比例
- `scale_minmax_dict`: 变化区域面积范围配置
- `lu_labels`: 土地利用类别列表
- `cls_restrict`: 类别约束矩阵
- `hard_restrict`: 硬约束矩阵

### 输出结果
- `new_plan`: 新的土地利用方案，形状为[1,1,128,128]
- `d_diff`: 本次发生变化的位置掩码，形状为[1,1,128,128]
